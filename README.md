# 🎬 ScriptCast Studio (Bare React Native)

> A 100% offline, native mobile teleprompter, vocal coach, and facecam video recorder built with **Bare React Native (JSX)** and **VisionCamera 5**.

---

## 🤖 AI / LLM Script Specification & Engine Guide

ScriptCast Studio features a built-in **Script Loader Engine** (`src/utils/scriptLoaderEngine.js`) that automatically validates, paces, and parses video scripts generated by any AI (ChatGPT, Claude, Gemini, DeepSeek, Llama, etc.) or written manually.

### 📋 Universal LLM Prompt (Copy-Paste to Any AI)

When asking an AI model to generate a custom video script for this app, copy and paste this exact prompt:

```markdown
You are an expert video copywriter and teleprompter coach for "ScriptCast Studio".
Generate a high-converting, paced short-form video script about: "[INSERT TOPIC HERE]".

You MUST output ONLY a valid raw JSON object matching the exact specification below. Do not wrap in commentary or markdown conversational text.

{
  "title": "Short, compelling video title",
  "category": "Educational",
  "targetWpm": 150,
  "beats": [
    {
      "id": "beat-1",
      "section": "HOOK",
      "spokenText": "The exact words spoken aloud in this beat. Keep it punchy.",
      "cues": "Stage direction for eye-contact, gesture, or expression (e.g. Look dead into lens, lean in)",
      "tone": "hook",
      "pauseAfterSec": 1.2,
      "emphasisWords": ["exact", "words"]
    },
    {
      "id": "beat-2",
      "section": "PROBLEM",
      "spokenText": "The core struggle, myth, or pain point being addressed.",
      "cues": "Conversational, subtle head nod",
      "tone": "problem",
      "pauseAfterSec": 1.0,
      "emphasisWords": ["struggle", "pain"]
    },
    {
      "id": "beat-3",
      "section": "SOLUTION",
      "spokenText": "The breakthrough method, explanation, or key takeaway.",
      "cues": "Upright posture, confident tone",
      "tone": "solution",
      "pauseAfterSec": 1.0,
      "emphasisWords": ["breakthrough"]
    },
    {
      "id": "beat-4",
      "section": "CTA",
      "spokenText": "Follow for more daily insights and comment your question below.",
      "cues": "Friendly smile, nod towards camera",
      "tone": "cta",
      "pauseAfterSec": 1.5,
      "emphasisWords": ["Follow", "comment"]
    }
  ]
}

CRITICAL RULES:
1. Each beat represents a single recording take (1 to 3 sentences maximum).
2. "tone" must be one of: "hook", "problem", "solution", "thoughtful", "cta", or "default".
3. "pauseAfterSec" is the rest period after speaking before cutting to the next take (typically 0.8s to 1.5s).
4. "emphasisWords" are words that will be dynamically highlighted on the speaker's teleprompter screen.
5. "cues" guide the speaker's body language and eye contact with the front lens.
```

---

### 📄 JSON Schema Reference

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | `string` | **Yes** | Video title displayed in Gallery and Prompter header. |
| `category` | `string` | No | Category tag (e.g. `"Tech"`, `"Shorts"`, `"Educational"`). Defaults to `"General"`. |
| `targetWpm` | `number` | No | Speaking pace in Words Per Minute (e.g., `140`–`160`). Defaults to `150`. |
| `beats` | `array` | **Yes** | Non-empty array of Beat objects. |

#### Beat Object:
| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | No | Unique ID (e.g. `"beat-1"`). Auto-generated if omitted. |
| `section` | `string` | No | Narrative beat name (e.g. `"HOOK"`, `"PROBLEM"`, `"SOLUTION"`, `"CTA"`). |
| `spokenText` | `string` | **Yes** | The actual words the creator will speak into the camera lens. |
| `cues` | `string` | No | Physical/facial stage cue displayed above the teleprompter text. |
| `tone` | `string` | No | Vocal coaching tone preset (`hook`, `problem`, `solution`, `thoughtful`, `cta`, `default`). |
| `pauseAfterSec` | `number` | No | Pause duration in seconds before ending take. Defaults to `1.0`. |
| `emphasisWords` | `string[]` | No | List of key words to highlight on the teleprompter screen. |

### 🎙️ Supported Tone Profiles & Prompter Directives

| Tone | Vocal Style | Prompter Directive |
|---|---|---|
| `"hook"` | High Energy & Urgent | Punch the first 3 words. Lock eyes with front lens. |
| `"problem"` | Empathic & Conversational | Slow down. Conversational, one-on-one cadence. |
| `"solution"` | Authoritative & Confident | Crisp vocal authority with steady pitch. |
| `"thoughtful"` | Measured & Analytical | Lower pitch slightly, leave room for pauses. |
| `"cta"` | Warm & Action-Oriented | Friendly smile, make following effortless. |
| `"default"` | Natural | Relaxed, natural conversational breathing. |

### 📝 Alternative Tagged Text / Markdown Format

The Script Loader Engine also automatically parses tagged plain text:

```markdown
[HOOK] (Look directly into lens with high energy)
Stop scrolling, because this one psychological trick will make anyone listen to you instantly.
[pause 1.2s]

[PROBLEM] (Conversational, subtle head nod)
Most people talk way too fast when they get nervous, and their pitch goes up like this.
[pause 1.0s]

[SOLUTION] (Lean in, warm and authoritative tone)
Take a breath, lower your voice by half an octave, and embrace the silent pause.
[pause 1.0s]

[CTA] (Friendly smile, energetic outro)
Try this in your next conversation, and hit follow for more communication secrets!
[pause 1.5s]
```

## 🏗️ Core Architecture & Layering

To ensure a **Clean Studio Video Export**, the application strictly separates the camera recording layer from the teleprompter UI layer:

- **Layer 0 (Background):** `<Camera>` from `react-native-vision-camera`. This captures raw hardware sensor data only.
- **Layer 1 (Foreground/UI):** `<View style={StyleSheet.absoluteFill}>` covering the camera. Holds the live teleprompter text, audio VU meters, and recording controls.

Because `VisionCamera` records directly from the camera sensor, **the teleprompter UI, captions, and buttons will NEVER be burned into the exported MP4 video**.

## 📱 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Android Run
Ensure an Android device or emulator is connected via ADB:
```bash
npx react-native run-android
```

### 3. Start Metro Bundler
```bash
npx react-native start
```
