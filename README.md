# 🎬 ScriptCast Studio (Bare React Native)

> A 100% offline, native mobile teleprompter, vocal coach, and facecam video recorder built with **Bare React Native (JSX)**.

---

## 🏗️ Core Architecture & Layering

To ensure a **Clean Studio Video Export**, the application strictly separates the camera recording layer from the teleprompter UI layer:

- **Layer 0 (Background):** `<Camera>` from `react-native-vision-camera`. This captures raw hardware sensor data only.
- **Layer 1 (Foreground/UI):** `<View style={StyleSheet.absoluteFill}>` covering the camera. Holds the live teleprompter text, audio VU meters, and recording controls.

Because `VisionCamera` records directly from the camera sensor, **the teleprompter UI, captions, and buttons will NEVER be burned into the exported MP4 video**.

---

## ⚡️ Key Modules & Features

### 1. Script Parser (`src/utils/scriptParser.js`)
- Parses raw scripts generated by ChatGPT, Claude, Gemini, or written manually.
- Identifies section tags (`[HOOK]`, `[PROBLEM]`, `[SOLUTION]`, `[CALL TO ACTION]`).
- Extracts stage cues like `(look directly into lens)`.
- Calculates estimated duration based on target **WPM** (Words Per Minute).

### 2. Live Prompter (`src/components/Prompter.jsx`)
- Powered by `react-native-reanimated` (`useSharedValue` and `withTiming`) to linearly translate the Y-position of the text at the target WPM (zero JS thread stutter).
- **Dynamic SPEAK NOW Cue**: Highlights spoken words in real time based on pacing rhythm.
- Eye-line target keeping creator focused directly on the phone's front camera lens.

### 3. Audio VU Meter (`src/components/VUMeter.jsx`)
- Measures voice decibel level and maps RMS to a vertical Reanimated meter.
- Visual thresholds:
  - **Gray**: Noise Floor
  - **Green**: Optimal Studio Level (25% - 70%)
  - **Amber**: High Energy (70% - 88%)
  - **Red**: Clipping / Too Close (> 88%)

### 4. Beat-by-Beat Recording & Auto-Stitcher (`src/utils/videoStitcher.js`)
- Record sentence-by-sentence.
- Stumbled on a line? Tap **Retake Beat** to overwrite the take without losing previous recordings.
- **Auto-Stitcher**: Uses `ffmpeg-kit-react-native` to concatenate all approved takes without re-encoding:
  1. Writes `inputs.txt` into the device cache:
     ```text
     file '/path/to/take1.mp4'
     file '/path/to/take2.mp4'
     ```
  2. Runs:
     ```bash
     ffmpeg -f concat -safe 0 -i inputs.txt -c copy output.mp4
     ```

## 📱 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. iOS Setup
```bash
cd ios
bundle install
bundle exec pod install
cd ..
npx react-native run-ios
```

### 3. Android Setup
Ensure an Android emulator or physical device is connected:
```bash
npx react-native run-android
```

### 4. Start Metro Bundler
```bash
npm start
```
